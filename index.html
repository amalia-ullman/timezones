Timezones Scaled Against Distance

Since time changes based on location (commonly referred to as 'timezones'), this project explores what would happen if the change in time based on location was constant, meaning each location has a unique 'true time'. With a step of 1, the eastern and western extremities of each US timezone are used to determine the minutes per mile conversion, as one hour passes between the longitudinal component of the distance between these points. Clicking on a location uses this minutes per mile conversion to determine the amount of minutes one should add to the time at that location to find the true time.
